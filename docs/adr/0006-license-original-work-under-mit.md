# License Hunter Pi original work under MIT

Hunter Pi original source code and documentation will use the MIT License. Pi and Oh My Pi also use MIT at the frozen research references, and a permissive license fits the goal of interoperating with the Pi package ecosystem without requiring a source fork. Third-party material retains its own license and must pass the repository's NOTICE/provenance gate before incorporation or publication.

## Consequences

- The root `LICENSE` grants MIT terms only for material the Hunter Pi copyright holder can license.
- `NOTICE.md` distinguishes original work, dependencies, research references, and incorporated third-party material.
- Every copied or adapted source unit requires an immutable provenance record, retained notices, and license-compatibility review.
- Unknown or incompatible terms block incorporation; architectural inspiration is reimplemented independently rather than copied without permission.
- This resolves the Task 1 license prerequisite but does not authorize npm/installer publication.
