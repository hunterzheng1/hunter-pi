# Pi 0.84.1 与 Windows 安装分发

日期：2026-08-13

## 目标

1. 将精确 Pi Engine Release 从 `0.83.0` 更新到 `0.84.1`，并验证 Extension、JSON、RPC、SDK 公开接口。
2. 适配 JSON/RPC delta-only `message_update`，继续把最终 `message_end` 作为 Provider 用量和完成观察的权威消息。
3. 发布 Windows x64 unsigned developer-preview：`install.ps1`、`hpi-windows-x64.zip` 和 SHA-256 文件。
4. 证明用户无需预装 Node.js、npm 或 Pi，即可在用户目录下完成隔离安装并从新终端运行 `hpi`。
5. 保留现有 update manager 的资格、激活、回滚和追加历史；安装脚本不得覆盖不同的活动 release。

## 不在范围内

- 真实 Provider 请求或新的付费请求；
- 真实用户仓库；
- 修改现有 `%USERPROFILE%\.hunter-pi`；
- 卸载或覆盖全局 npm `hpi`；
- 代码签名、Stable 渠道、生产就绪或新的日常使用 `GO`；
- 把 0.83 的 Task 12 Evidence 迁移为 0.84.1 Evidence。

## 实施顺序

1. 读取上游 Release、固定 npm/Git/SRI 身份，记录研究结论。
2. 先写失败契约，再升级依赖和公开接口探针。
3. 先写失败安装测试，再实现唯一来源 `scripts/install.ps1` 和 ZIP 资产生成器。
4. 在临时目录验证本地目录、ZIP、校验失败、PATH 幂等、命令冲突、既有状态隔离和稳定命令。
5. 复跑 portable 多版本激活、资格更新、篡改拒绝和回滚测试。
6. 完成本地门禁，合并并推送 `main`，要求精确 merged-head Windows/Ubuntu CI 全部通过。
7. 从精确 CI portable artifact 生成发布资产，创建预览 tag/Release，再从真实 GitHub URL 进行一次隔离安装。
